How machines work

Components take up space in your machine's grid. Each has sockets (the circles) that want a certain element: a matching rune powers it fully, a different element only 40%, and higher-rank runes are worth more (rank II = 2×, III = 4×…). Many components boost the components they touch, so placement matters. Three identical components in storage forge into a stronger one. Resonance is your machine's total power: it unlocks harder Rift Tiers. If your machine is destroyed in the Rift, each installed component (and socketed rune) has a 30% chance to be lost.
